## Usage

```tsx
import {
  CodeBlock,
  CodeBlockCopyButton,
  CodeBlockHeader,
  CodeBlockLanguage,
  CodeBlockTitle,
} from "@/components/ui/code-block"
```

```tsx
<CodeBlock code={code} language="typescript" showLineNumbers>
  <CodeBlockHeader>
    <CodeBlockTitle>example.ts</CodeBlockTitle>
    <CodeBlockLanguage />
    <CodeBlockCopyButton className="ml-auto" />
  </CodeBlockHeader>
</CodeBlock>
```

## Features

### Line Numbers

Enable numeric gutter indicators using the `showLineNumbers` prop. Numbers are rendered with pseudo-elements to avoid interfering with copy operations.

### Highlighted Lines

Emphasize specific lines with the `highlightedLines` prop using comma-separated ranges or line numbers (e.g. `highlightedLines="2,4-6"`).

### Collapsible Blocks

Constrain height on lengthy source code snippets using `maxLines={18}` coupled with `<CodeBlockExpandButton />` for one-click unfolding.

### Diff & Patch Mode

Highlight additions and removals natively via `diff={{ added: "2-4", removed: "6" }}` or by parsing unified git patches.

## API Reference

### CodeBlock

Syntax-highlighted code surface powered by Shiki with line numbers, diff mode, and collapsible support.

| Prop | Type | Default |
| :--- | :--- | :--- |
| `code` | `string` | - |
| `language?` | `string` | `"typescript"` |
| `showLineNumbers?` | `boolean` | `false` |
| `highlightedLines?` | `string` | - |
| `maxLines?` | `number` | - |
| `diff?` | `{ added?: string; removed?: string }` | - |
| `className?` | `string` | - |

### CodeBlockHeader

Top control bar housing filename title, language tag, and copy affordance.

| Prop | Type | Default |
| :--- | :--- | :--- |
| `className?` | `string` | - |
| `children` | `React.ReactNode` | - |

### CodeBlockCopyButton

Animated one-click clipboard copy button with check feedback icon.

| Prop | Type | Default |
| :--- | :--- | :--- |
| `className?` | `string` | - |
| `position?` | `"default" \| "pinned"` | `"default"` |
