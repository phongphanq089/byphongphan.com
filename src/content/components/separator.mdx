## API Reference

### Separator

A visual divider component based on Radix UI Separator Primitive.

| Prop | Type | Default |
| :--- | :--- | :--- |
| `orientation?` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `decorative?` | `boolean` | `true` |
| `className?` | `string` | - |
