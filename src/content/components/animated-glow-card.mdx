## Technical Insights & Architecture

This component uses zero-dependency CSS custom properties to ensure 60fps hardware-accelerated rendering without triggering React re-render cycles on mouse move events:

1. **Bounding Box Relative Coordinates**: The parent `CardCanvas` computes `e.clientX - rect.left` and `e.clientY - rect.top`.
2. **CSS Variable Binding**: Values are directly injected into `element.style.setProperty('--mouse-x', ...)`.
3. **Radial Gradient Mask**: Child cards calculate a radial gradient centered at `var(--mouse-x)` and `var(--mouse-y)`, illuminating only the card perimeter underneath the cursor.
