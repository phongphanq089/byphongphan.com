## Usage

```tsx
import { CardCanvas, GlowCard } from "@/components/animated-glow-card"

<CardCanvas className="p-4">
  <GlowCard className="w-full max-w-sm" showCrosshairs={true}>
    <h3 className="font-semibold">Interactive Card</h3>
    <p className="text-xs text-muted-foreground">Specular highlight card</p>
  </GlowCard>
</CardCanvas>
```

## Technical Insights & Architecture

This component uses zero-dependency CSS custom properties to ensure 60fps hardware-accelerated rendering without triggering React re-render cycles on mouse move events:

1. **Bounding Box Relative Coordinates**: The parent `CardCanvas` computes `e.clientX - rect.left` and `e.clientY - rect.top`.
2. **CSS Variable Binding**: Values are directly injected into `element.style.setProperty('--mouse-x', ...)`.
3. **Radial Gradient Mask**: Child cards calculate a radial gradient centered at `var(--mouse-x)` and `var(--mouse-y)`, illuminating only the card perimeter underneath the cursor.

## API Reference

### CardCanvas

Interactive mouse-tracking wrapper establishing bounding dimensions and local CSS variables (`--mouse-x`, `--mouse-y`).

| Prop | Type | Default |
| :--- | :--- | :--- |
| `children` | `React.ReactNode` | - |
| `className?` | `string` | - |

### GlowCard

Specular gradient border card with dynamic hover glow and architectural reticle crosshairs.

| Prop | Type | Default |
| :--- | :--- | :--- |
| `showCrosshairs?` | `boolean` | `true` |
| `className?` | `string` | - |
| `contentClassName?` | `string` | - |
