## Usage

```tsx
import { MiddleTruncation } from "@/components/ui/middle-truncation"

export function Example() {
  return (
    <div className="w-64">
      {/* Preserves 8 characters at the end (e.g. extension) */}
      <MiddleTruncation end={8}>
        very-long-project-name-production-deployment-v2.final.tsx
      </MiddleTruncation>

      {/* Balanced split preserving at least 6 characters at the end */}
      <MiddleTruncation minEnd={6} ellipsis="···">
        0x71C6633279268a2F7c09361730a8435d8eFEb947
      </MiddleTruncation>
    </div>
  )
}
```

## Features

- **Binary Search Algorithm:** Uses sub-millisecond binary search to compute the exact truncation cutoff in $O(\log N)$ time.
- **Canvas 2D Measurement:** Accurately measures text width matching computed CSS font styling without DOM reflows.
- **ResizeObserver with RAF Debouncing:** Syncs layout adjustments directly with the browser's paint cycle for jank-free responsiveness.
- **SSR Safe:** Gracefully handles server-side environments with fallback measurement and isomorphic layout effects.
